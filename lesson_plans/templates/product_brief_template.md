# Product Brief — `[Your App Name]`

*A one-page brief. Keep it short. This is the forming-intent artifact Claude Code will use to build your app, and you'll keep editing it as you learn more.*

---

## 1. The Problem

**One or two sentences. What's broken in the world that this app addresses?**

Good: *People who want to journal consistently give up within a week because every app asks them to write too much before they see any value.*

Bad: *There is no good journaling app.* (Too vague — what's actually wrong?)

## 2. The Target User

**Who is this for? Be specific. Not "everyone." Not "students." A real person you can picture.**

Include:
- Who they are (role, life situation)
- What they're trying to do when they'd reach for your app
- Why the current options don't work for them

> *Write yours here:*

---

## 3. The Core Flow

**Describe the single most important thing a user does in your app. Start to finish. Numbered steps.**

This is the "happy path" — one user, one goal, one session. Don't describe every feature. Just the one flow that defines the product.

Example:
1. User opens the app
2. Sees a single prompt: "What's one thing you noticed today?"
3. Taps to type a short response (no formatting, no length requirement)
4. Taps Save
5. Sees a simple confirmation and a streak counter
6. Closes the app

> *Write yours here:*

---

## 4. Success Criteria

**How will you know this app is working? Pick 1–3 signals.**

These can be qualitative ("a friend used it for a week without abandoning it") or quantitative ("75% of first-time users complete the core flow"). Don't pick vanity metrics like total downloads.

> *Write yours here:*

---

## 5. Out of Scope

**What is this app deliberately NOT doing? List 3–5 things.**

This is often the most valuable section. It prevents scope creep when Claude Code (or you) gets tempted to add features.

Examples:
- No social features (no sharing, no followers, no comments)
- No notifications beyond the one daily reminder
- No account system in v1 — data stays on device
- No categories, tags, or folders
- No dark mode customization — one theme only

> *Write yours here:*

---

## Review Checklist (before handing this to Claude Code)

- [ ] Could a stranger read this and describe the app back to you correctly?
- [ ] Is the target user a specific person, not a demographic?
- [ ] Does the core flow describe one user doing one thing — not a feature list?
- [ ] Is the "out of scope" section doing real work (cutting things you were tempted to include)?
- [ ] Did you write this *after* talking to potential users, or before? (The brief is stronger if it's downstream of real conversations.)
