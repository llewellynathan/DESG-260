
# Assignment 2: Make It Better App
## “One More Thing”
“One more thing” became a catchphrase of Steve Jobs during his famous Apple launches. After showcasing a wonderful product, he’d surprise the audience by saving the best feature for last. 

And yet, even with all of the amazing digital software products we use everyday, isn’t there


# ✏️ The Assignment
## project 01: make it better
How many times have you started using an app and thought “I could make this better”? That’s what we’ll be doing. For the first project, you will add a feature/user interaction to one of the default Apple iOS or Google Android applications (Contacts, Phone, Reminders, Messages, Stocks, Weather, Mail, etc.).

You will research, design and prototype the new interaction such that your additions will be consistent with the original application’s design language and pass usability tests and still accomplish the core function of the original app. Design your app for the latest phone and operating system possible. 
 
This project will introduce you to processes and concepts to improve your user experience skills and critical thinking.

# 🚃 Process
## Deliverable
Well-designed documentation PDF that includes this information (most of these components will be completed as small exercises first and then will be integrated into the full project documentation). The documentation should demonstrate a cohesive format with clear typographic hierarchy and carefully chosen grids, typefaces, and layout, illuminating the app design, not clashing with nor overshadowing it. 
 
The PDF should include the following:
 
1. Title Page with Creative Brief (goal of the new interaction)
2. User Flow of Existing App (with critique: pros/cons)

3. Competitive Analysis (your research)
    a. Top-level competitive analysis of 5 apps (current iOS app + 3 other apps + 1 physical)
    b. Quadrant positioning chart
4. User task diagrams
    a. Complete user flow of existing app
    b. Modified user flow with your new feature added

(these can be on the same page or two separate pages; make sure the new feature is clearly demarcated from the original using color or similar visual separator)
5. Paper prototype + other iterative prototypes (either digital wire-frames or other iterative designs)    

    a. Show feedback from user tests / notes about behind-the-scenes features  
    b. Include the first prototype, make clear where your edits came—demonstrate your iterative design process. 
    c. Note your ideas and reasoning for creative choices.
    d. no need to include device mock-ups

6. High-fidelity final prototype 

    a. Show the finished design in all of its glory (include device mock-up)
    b. Should be indistinguishable from Apple or Google default apps
    c. Include annotations about features or careful design decisions
