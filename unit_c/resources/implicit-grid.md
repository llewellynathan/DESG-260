# Implicit Grid

> **The implicit grid is the systematic negative space between all interface elements—consistent spacing without rigid constraints.**

## Components
1. **Explicit grid** — Fixed horizontal and vertical divisions; use as a general guide, not law
2. **Implicit grid** — Implied spacing rhythm; adapts to dynamic content and screen sizes

## Essential Practices
- Use 4px increments for all spacing decisions (4, 8, 12, 16, 20, 24...)
- Stay diligent and consistent—this creates the "clean" feel
- Think of grids as flexible containers, not fixed structures
- Even numbers divide in half cleanly; avoid 5px or 10px increments

## Quick Reference
- **Base increment**: 4px (or 8px if you prefer)
- **Page padding**: Start at 16px, adjust to 8–24px as needed
- **Why 4px**: Divides evenly, aligns with 16px (1em) browser default
- **Half increments**: 2px adjustments are acceptable when intentional
- **Small differences matter**: Even 4–8px changes impact the details
