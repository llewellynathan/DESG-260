# Font Sizes

> **Limit yourself to a maximum of four type sizes—constraint creates consistency.**

## Components
1. **Titles** — Primary headings (e.g., 17pt in iOS)
2. **Subtitles** — Secondary text and body copy (e.g., 15pt)
3. **Actions** — Buttons and links (e.g., 13pt)
4. **Metadata** — Timestamps and labels (e.g., 11pt)

## Essential Practices
- Start with 3-4 sizes and use them exclusively
- Adjust sizes at a global level, not per element
- Create variety with color, weight, and case—not more sizes
- Reuse sizes across sections instead of inventing new ones

## Quick Reference
- **Size jumps**: Minimum 2px between sizes (avoid 14px vs 13px)
- **UPPERCASE**: Reads one size larger—use for section titles or CTAs
- **Per-section rule**: Apply four-size limit to each distinct area on larger sites
- **Single size**: Can work when combined with weight, style, and whitespace
