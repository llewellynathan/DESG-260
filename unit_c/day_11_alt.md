# Day 11 (Alt) — Tuesday, Feb 17
## Unit C: Hierarchy & Responsive Web

**Focus:** Grids are invisible scaffolding — using AI to learn grid systems, then applying them.

**Targeted Learning Outcomes:**
- Better Interactions & Experiences
- Critical Analysis of Form and Format
- Design Strategy

---

### Desired Results

**Essential Questions:**
- EQ1: How do grids enable both consistency and flexibility?
- EQ2: What's the difference between designing for mobile-first vs. desktop-first?
- EQ3: How do you use AI to learn new design concepts effectively?

**Understandings:**
- U1: Grids create consistency and enable faster, more confident design decisions
- U2: Responsive design requires thinking in systems, not fixed layouts
- U3: Strategic AI use requires knowing which learning phase you're in (acquisition vs. strengthening)

**Students Will Know:**
- K1: The box model (content, padding, border, margin) and how element size is calculated
- K2: How to set up and use layout grids in Figma (columns, margins, gutters)
- K3: The 4px increment system for consistent spacing (implicit grid)
- K4: Common grid patterns for mobile and desktop (4-column mobile, 12-column desktop)
- K5: The difference between acquisition practices and strengthening practices

**Students Will Be Able To:**
- S1: Apply AI learning practices to a new design topic (grids)
- S2: Create responsive frames in Figma with proper grid setup
- S3: Design a layout that works across mobile and desktop breakpoints

### Activities

1. **Warm-Up: Grid Detective** (10 min) `[EQ1, U1, K2]`
   - Prompt on screen: "Open a well-designed website. Can you find the grid? How many columns? Where are the margins?"
   - Students screenshot and annotate with grid overlay guesses
   - Quick share: 2-3 examples — what patterns emerge?

2. **Today's Learning Goals** (5 min) `[EQ1, EQ2, EQ3]`
   - Today's focus: applying AI learning practices to grid systems
   - You practiced the two-phase framework with typography. Today you apply it to grids.
   - By end of class: understand grids AND have them set up in Figma for your PDP

3. **Brief Review: Two-Phase Framework** (5 min) `[U3, K5]`
   - Quick visual reminder of Phase 1 (Taking In) and Phase 2 (Strengthening)
   - **Taking In:** Scope First, Why First, Chunk It, Translate, Verify
   - **Strengthening:** Teach Back, Quiz Me, Minimum Hint, Socratic Mode
   - "You practiced this with typography. Today we apply it to a new topic: grids."

4. **I do / We do / You do: Learning with AI** (24 min) `[EQ3, U3, K5, S1]`

   *I do: Model Acquisition Practices Live* (8 min)
   - Topic: **Visual rhythm and spacing** (not grids yet)
   - "I want to learn about visual rhythm in design. Watch how I use AI."
   - Demo live with AI:
     - **Scope First:** "I want to learn about visual rhythm and spacing in design. Can you break this topic down into the main sub-topics I should understand?"
     - **Chunk It:** "Let's start with just one of those. Explain [first sub-topic] to me."
     - **Translate:** "Can you give me an analogy for how visual rhythm works? Something from everyday life?"
   - Narrate your thinking: "Notice how I'm actively directing the conversation, not just absorbing."

   *We do: Class Practices Together* (8 min)
   - Continue learning visual rhythm using the practices
   - Ask class: "What practice should we use next?"
   - Students suggest which practice to apply
   - Instructor types what the class decides, shows AI response
   - Key: Students are practicing CHOOSING practices, not just watching

   *You do: Pairs Practice* (8 min)
   - Same topic: visual rhythm
   - Partner A: Try an acquisition practice (Chunk It or Translate) — learn something new
   - Partner B: Try a strengthening practice (Teach Back) — explain what you learned so far to AI
   - Swap roles after 4 minutes
   - Quick debrief: "What felt different about taking in vs. strengthening?"

5. **Introduce C3: Mobile + Desktop Wireframes** (5 min) `[S3, U2]`
   - **Due: Wed, Feb 18 @ 11:59pm**
   - Requirements:
     - Simple wireframes for both mobile and desktop PDP
     - Show: product title + details, image placements, button placements, page layout
     - Focus on structure, not visual polish
   - These wireframes become the foundation for high-fidelity work
   - Reminder: same content, different arrangement — let the grid guide you

6. **AI-Guided Grid Systems Lab** (50 min) `[EQ1, EQ2, K1, K2, K3, K4, S1, S2, U1, U2]`
   - **Connection:** "Visual rhythm IS what grids create — just as visual hierarchy is what typography creates."
   - Use the two-phase framework to learn grid concepts:

   **Topics to explore:**
   - The box model (content, padding, border, margin)
   - Layout grids (columns, margins, gutters)
   - The 4px increment system (implicit grid)
   - Responsive patterns (4-column mobile, 12-column desktop)
   - Mobile-first vs. desktop-first thinking

   **Phase 1: Taking In (if grids are new)**
   - **Scope First** — "What are the key concepts I need to understand about grid systems in web/UI design?"
   - **Chunk It** — Learn one concept at a time (box model, then layout grids, then responsive patterns)
   - **Translate** — Ask for real website examples, analogies, visual explanations

   **Phase 2: Strengthening (once you have the basics)**
   - **Teach Back** — Explain the box model to AI in your own words. Ask it to check your understanding.
   - **Quiz Me** — "Quiz me on layout grids and the 4px increment system. Ask one question at a time."
   - **Socratic Mode** — If something doesn't click, ask AI to guide you with questions

   **Apply your learning:**
   - Set up grids in Figma (desktop: 12-column, mobile: 4-column)
   - What margins and gutters will you use? Why?
   - How does the grid help you place content consistently?

   **Reflection (last 5 min):**
   - What did I learn today about grids?
   - What am I still confused about?
   - Which practices did I use? Which phase was I in most of the time?

7. **Work Session: Wireframes** (21 min) `[S2, S3, EQ2]`
   - **Priority 1:** Set up Figma frames with proper grids (mobile + desktop)
   - **Priority 2:** Begin C3 wireframes (due Wed @ 11:59pm)
   - Instructor circulates for 1:1 feedback:
     - Are grids set up correctly? (columns, margins, gutters)
     - Does content align to the grid?
     - Does the mobile layout make sense for thumb-zone navigation?

**Total: 120 min** (Monday schedule on Tuesday due to Presidents' Day)
